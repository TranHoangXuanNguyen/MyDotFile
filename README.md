## 🛠️ Automated Installation Guide

I have provided an installation script to automate package installation and configuration setup.

### Step 1: Clone this repository

Open your terminal and run the following command to download the configurations:

```bash
git clone git@github.com:TranHoangXuanNguyen/MyDotFile.git ~/dotfiles
cd ~/dotfiles
```

### Step 2: Run the install script

Execute the automated install script:

```bash
chmod +x install.sh
./install.sh
```

**What does this script do?**
1. Asks if you want to install the necessary packages (Hyprland, Waybar, Rofi, etc.) via `pacman` and `yay`.
2. Automatically detects existing configuration files in your `~/.config/` directory and securely backs them up to `~/.config/cfg_backups/`.
3. Creates **symlinks** from the `~/dotfiles/configs/` directory to `~/.config/`. This ensures any future updates in this repo are instantly applied.

### Step 3: Reboot
Once the script finishes, logout or reboot your system to enjoy the new interface!
